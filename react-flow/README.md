# Easy graph JSON generation for testing purpose

## React Flow Installation

Navigate to this folder `react-flow-tester` (i.e., $pwd = here). Then, for installing:

```
npm create vite@latest react-flow-editor -- --template react
cd react-flow-editor
npm install
npm install @xyflow/react
npm run dev
```

Check installation was successful:

``` 
npm list @xyflow/react
```

If `(empty)` is shown, then try:

```
npm install @xyflow/react
```

## App.jsx file

In the *react-flow-tester*, there is `App.jsx` file.
After installing react flow, you will see `src` folder is created in the current path (inside the react-flow-tester folder). There, replace `src/App.jsx` with the one provided in the react-flow-tester.

## Run 

```
npm run dev
```
